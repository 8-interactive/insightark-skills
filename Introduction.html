SUPER 8 Studio InsightArk Skills
安裝設定指南

下載 Skills 套件

選擇來源，下載 Skills 套件到你的電腦。

來源
curl -LO https://downloads.no8.io/main/releases/skills/insightark-skills-latest.tar.gz
tar -xzf insightark-skills-latest.tar.gz
cd insightark-skills
Invoke-WebRequest -Uri "https://downloads.no8.io/main/releases/skills/insightark-skills-latest.tar.gz" -OutFile "insightark-skills-latest.tar.gz"
tar -xzf insightark-skills-latest.tar.gz
cd insightark-skills
💡 下載的套件包含 RELEASE 檔，安裝後的設定步驟會自動偵測 API 環境，不需手動選擇。 
git clone https://github.com/8-interactive/insightark-skills.git
cd insightark-skills
⚠️ Git checkout 沒有 RELEASE 檔，設定步驟時需手動選擇 API 環境。

安裝 Skills

執行安裝腳本，將 Skills 複製到你的 AI Agent 目錄。 

./install.sh
⚠️ Windows 用戶需在 Git Bash 或 WSL 中執行，不支援 CMD 或標準 PowerShell。
安裝精靈步驟
  1. 1選擇安裝模式：Per-agent（各 Agent 獨立目錄）或 共用資料夾
  2. 2選擇要安裝的 AI Agent（可多選）：Claude Code、Cursor、Codex、OpenCode、GitHub Copilot
  3. 3選擇安裝位置：~（使用者 Home 目錄）或自訂路徑
  4. 4確認安裝計畫後執行
安裝路徑對照表
Agent Skills 路徑
Claude Code ~/.claude/skills
Cursor ~/.cursor/skills
Codex ~/.codex/skills
OpenCode ~/.opencode/skills
GitHub Copilot ~/.copilot/skills

設定 API 憑證（通常由 install.sh 自動完成）

🔒
安全注意事項
  • 請勿將 .super8-studio.env 提交到版本控制
  • 請勿在聊天或 Email 中分享 Token
  • Token 有效期 6 個月，過期請重新執行 ./setup-env.sh
✅ install.sh 安裝時會自動執行憑證設定精靈，通常不需要額外操作。若需重新設定，請執行以下指令。 
./setup-env.sh
精靈執行流程
  1. 1自動從 RELEASE 檔偵測 API 環境（Production）
  2. 2自動開啟 Super 8 Console → Account Settings → Developer API，建立 Token
  3. 3貼上 Token（僅顯示一次，輸入時遮蔽）
  4. 4精靈列出已啟用 Developer API 的組織，選擇一個
  5. 5完成後將憑證寫入 ~/.super8-studio.env（權限 600）

驗證設定

確認憑證正確且 API 可連通。 

./setup-env.sh --check
成功輸出範例
✓ S8_API_URL https://api-next.no8.io
✓ S8_SESSION_TOKEN set (r:...)
✓ S8_ORG_ID org_xxx
✓ API reachable
✓ Auth valid
常見問題排除
🔑
Auth valid 失敗

Token 已過期，重新執行設定精靈： 

./setup-env.sh
🌐
API reachable 失敗

確認 API URL 是否對應正確環境： 

./setup-env.sh --api-url https://api-next.no8.io
🎉 設定完成！現在可以在你的 AI Agent 中使用 SUPER 8 Studio Skills 了。

解除安裝

移除所有已安裝的 Skills 及憑證設定。

⚠️ 解除安裝後，AI Agent 將無法使用 SUPER 8 Studio Skills。如需繼續使用，請重新執行安裝流程。
移除 Skills
./uninstall.sh
⚠️ Windows 用戶需在 Git Bash 或 WSL 中執行，不支援 CMD 或標準 PowerShell。
  1. 1顯示目前已安裝的 Skills 路徑清單
  2. 2確認後移除所有 Agent 目錄中的 Skills 檔案
移除憑證設定
rm ~/.super8-studio.env
Remove-Item "$env:USERPROFILE\.super8-studio.env"
