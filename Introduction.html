安裝設定指南

選擇 Host

InsightArk 透過各 AI host 的 plugin marketplace 安裝。請選擇你使用的 host。

Host Static OAuth client MCP manifest
Claude Codeinsightark-claude-code.mcp.json
Cursorinsightark-cursormcp.json
Codex CLI / ChatGPT desktopinsightark-codexcodex.mcp.json
💡 支援的顧客流程是安裝 host plugin後以 OAuth Connect。無需貼 SessionToken，也無需手動輸入 MCP URL。

安裝 Plugin

從 host marketplace 安裝 InsightArk plugin。安裝後會一併提供 workflow skills 與 bundled insightark MCP。

  1. 1開啟 Claude Code / Cursor / Codex 或 ChatGPT desktop 的 plugin marketplace
  2. 2搜尋並安裝 InsightArk Skills（或 SUPER 8 Studio InsightArk Skills）
  3. 3確認 plugin 已啟用，且 MCP server 名稱為 insightark
✅ Channel 會 bake MCP URL（staging / production）。顧客不需選擇 API 環境。

Connect / Authenticate

透過 host UI 完成瀏覽器 OAuth（靜態 public client，無需 DCR）。

各 Host 操作
  1. 1Claude Code：使用 /mcp 並 Connect / Re-authenticate insightark
  2. 2Cursor：Customize → Tools & MCP → Connect
  3. 3Codex CLI：必要時 codex mcp login insightark（已由 plugin 註冊，勿再 mcp add）
  4. 4ChatGPT desktop：App/plugin UI Connect / Reauthorize；不需 CLI
🔒 完成瀏覽器授權後，host 會保存 OAuth credential。請勿在聊天中貼任何 token。

驗證設定

請 agent 使用 insightark-session skill，呼叫 MCP auth_me。

Use insightark-session → auth_me
成功指標
✓ MCP connected insightark
✓ auth_me returns authenticated user
疑難排解
🔑
需要認證（401 / 403 / authentication-required）

使用 host Connect / Re-authenticate。網路錯誤、timeout、MCP unavailable 或 5xx 不是 OAuth 問題，請先檢查連線與 host MCP 狀態。

🌐
錯誤環境

從正確的 release channel 重新安裝 plugin（staging / production URL 已 bake）。

🎉 設定完成！可以開始使用 InsightArk skills。

登出、撤銷與卸載

這三件事不同，請分別處理。

  1. 1Host logout / clear-auth：清除本機 OAuth；之後需重新 Connect
  2. 2Console Connected Apps revoke：撤銷伺服器 refresh token family（plugin uninstall 不一定會做）
  3. 3Plugin uninstall：從 host marketplace / plugin manager 移除 plugin
⚠️ 不要假設「卸載 plugin」等於「撤銷 Console OAuth」。若需撤銷伺服器憑證，請到 Console Connected Apps。
