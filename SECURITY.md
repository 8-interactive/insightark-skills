# Security

## Reporting

Report security issues through your SUPER 8 Studio support channel.

## Revoking access

To revoke an agent's OAuth access:

1. In Super 8 Console, select your avatar in the lower-left corner.
2. Open the **User Information** tab.
3. Scroll to **Connected Apps**.
4. Revoke the relevant authorization.

Removing the marketplace plugin from an agent does not by itself revoke server-side OAuth tokens.
